# Decisions

Running log of choices made while building. Newest at the bottom.

## Prototype scope (2026-07-27)
- **No backend.** Per direction, Phase 1 is a client-side prototype. Supabase
  (auth, Postgres, Storage, edge function) is deferred. The build order's
  Steps 4 and 8 are replaced by local stubs:
  - `AuthStore` fakes a signed-in user on provider tap (no real OAuth).
  - CV "parsing" is a mock: a fixed delay + a canned JSON payload decoded
    through the *real* `CVParseResult` decoder, so the decoder and the confirm
    screen are production-shaped and swap straight onto the real edge function.
  - Persistence is `UserDefaults` (JSON), so force-quit/restore still works.
- Supabase SPM dependency removed from `project.yml` so the app builds offline.
  It goes back in when the backend lands.

## Stack / project
- Bundle id `ai.sofsuite.atlas`, iPhone-only, portrait-only (iPad out of scope).
- Xcode project is generated by XcodeGen and gitignored — edit `project.yml`,
  run `xcodegen generate`.

## Design
- **Display font:** General Sans not bundled yet. `TextRole` calls
  `Font.custom("GeneralSans-Bold", …)`, which SwiftUI silently falls back to
  SF Pro Display when the font is absent. To activate: drop
  `GeneralSans-Bold.otf` into `Atlas/Resources/Fonts/`, add it to the target
  resources and to `UIAppFonts` in `project.yml`. One-line change, no code.
- Dark mode locked off with `.preferredColorScheme(.light)` — Phase 2 ticket.
- Line-height is approximated with SwiftUI `lineSpacing` (target − font size);
  SwiftUI has no direct line-height API.

## Deferred to Phase 2 (tickets)
- Sign in with Apple (App Store Guideline 4.8 — mandatory before public release).
- Real Supabase backend + `parse-cv` edge function (Anthropic).
- Dark mode.
- LinkedIn CV import (platform limit: LinkedIn OIDC returns name/email/photo
  only — the button stays visible but inert with an honest caption).
